# Changelog

## 0.1.0 - 2026-04-27

- Initial self-hostable MVP stack with FastAPI, PostgreSQL/pgvector image, Redis and Next.js.
- Added campaign, character, NPC, quest, lore, message, combat, dice, ruleset, LLM request and tool audit models.
- Added built-in D&D-compatible, DSA-compatible and custom ruleset profiles.
- Added mock, OpenAI-compatible and Anthropic provider abstraction.
- Added dice parser, ruleset check engine, context builder, lore importer and prompt-injection warning detection.
- Added web UI for campaign console, chat, character/NPC/quest views and ruleset overview.
- Added tests for dice, importer, rulesets and tool audit behavior.
